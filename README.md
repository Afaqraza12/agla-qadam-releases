### 📱 How to Install on Android

1. Download the `.apk` file from the link above.
2. Tap the downloaded file in your browser or Notification shade to install.
3. If prompted with **"Install unknown apps"** or **"File might be harmful"**:
   - Tap **Settings** / **Details**
   - Enable **"Allow from this source"** or select **"Install anyway"**.
4. Open **Agla Qadam** and start testing!
